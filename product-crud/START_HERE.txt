ESSENTIALS (ONTHOUD DEZE!)
===========================

1. ENTITY (Model)
   └─ PHP klasse met #[ORM\...] attributes
   └─ Properties = database kolommen
   └─ Voorbeeld: Category.php

2. RELATIE (Connection)
   └─ OneToMany: 1 → veel  (Category → veel Products)
   └─ ManyToOne: veel → 1  (Product → 1 Category)
   └─ Staat in beide entities!

3. MIGRATIE (Database versioning)
   └─ Weg: Entity → make:migration → doctrine:migrations:migrate → Database
   └─ SQL tabellen worden AUTOMATISCH aangemaakt

4. REPOSITORY (Database queries)
   └─ Custom SELECT methodes
   └─ Used in Controller

5. CONTROLLER (Routes)
   └─ 5 actions: CREATE, READ (2x), UPDATE, DELETE
   └─ Haalt data via Repository
   └─ Geeft terug naar Template

6. FORM (Validatie & HTML)
   └─ FormType class
   └─ Valideert automatisch

7. TEMPLATE (Weergave)
   └─ Twig template files
   └─ Master = lijst, Detail = 1 item

COPY/PASTE TEMPLATES
====================

Kopieër deze voor snel werken:

ENTITY:
```php
#[ORM\Entity]
#[ORM\Table(name: 'your_table')]
class YourEntity {
    #[ORM\Id]
    #[ORM\GeneratedValue]
    #[ORM\Column]
    private ?int $id = null;

    #[ORM\Column(length: 100)]
    private ?string $name = null;
    // + getters/setters
}
```

ONETOMANY:
```php
#[ORM\OneToMany(targetEntity: Product::class, mappedBy: 'category')]
private Collection $products;
```

MANYTOONE:
```php
#[ORM\ManyToOne(targetEntity: Category::class, inversedBy: 'products')]
private ?Category $category = null;
```

CONTROLLER CREATE:
```php
#[Route('/create', name: 'create', methods: ['GET', 'POST'])]
public function create(Request $r, EntityManagerInterface $em) {
    $obj = new Entity();
    $form = $this->createForm(EntityType::class, $obj);
    $form->handleRequest($r);
    if ($form->isSubmitted() && $form->isValid()) {
        $em->persist($obj);
        $em->flush();
        return $this->redirectToRoute('index');
    }
    return $this->render('form.html.twig', ['form' => $form]);
}
```

GOLDEN RULES
============

1. ✅ Entity EERST - definieer data model
2. ✅ Migratie - zet in database
3. ✅ Controller - zet routes
4. ✅ Template - zet HTML
5. ✅ Form - zet validatie

⚠️ ONTHOUDEN:
- $entityManager->persist($obj)
- $entityManager->flush()
- csrf_token() in DELETE forms
- path('route_name', {id: value})
- {% for item in items %} in Twig
